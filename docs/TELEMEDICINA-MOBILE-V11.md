# Telemedicina Mobile V11 — alinhamento dos cards

Decisão visual permanente para o módulo `/telemedicina/` em dispositivos móveis.

## Regra

Os cards de acompanhamento devem apresentar o conteúdo textual centralizado para melhorar a leitura na visualização em lista e na grade 2×2.

A centralização inclui:

- nome do paciente;
- conduta/resolutividade resumida;
- especialidade;
- data da última consulta;
- selo de situação;
- data-alvo do retorno;
- datas dos avisos;
- rótulos dos botões de ação.

## Limites

- a regra vale somente para o resumo visual do card;
- formulários sanfonados de edição e histórico mantêm sua própria composição e não são centralizados por esta regra;
- o desktop permanece inalterado;
- nenhuma regra de negócio, dado clínico, contagem, filtro ou permissão é modificada.
