# HF-CHEFE — Chefe de hífen: conservar a condição e a exceção

**Rascunho para revisão, não publicado.** Rascunho local desativado; parecer pedagógico independente concluído sem correções.

Fonte editorial: [hf-chefe-v1.mjs](hf-chefe-v1.mjs). Regenerar com `node docs/missao-bancaria/rascunhos/validate-mp01.mjs --unit=hfchefe --render`.

Objetivo: Decidir o hífen pela formação, condição e exceção ensinadas, aplicando grafias em frases sem transformar o recorte em regra universal.

<a id="entrada"></a>

## 1. Doze itens próprios

Seis grupos retomam as três aulas. Nos itens de formação, os elementos são fornecidos; nos compostos/locuções, o repertório foi ensinado. Explique a condição ou a forma convencional e o erro do distrator. Este Chefe não é avaliação independente, cobertura integral de hífen ou prova de retenção.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="primeiro"></a>

## 2. H, vogais iguais e co

Nos casos ensinados, base com h usa hífen; contato de vogais iguais também, como auto-observação e semi-interno. Co com o aglutina-se nos exemplos coobrigação/coocupante. A exceção não apaga a condição dos outros primeiros elementos.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="contato"></a>

## 3. Diferentes, r/s e inter

Autoaprendizagem/extraescolar: vogais diferentes, sem hífen. Contrarregra/minissaia/microssistema: primeiro em vogal, base em r/s, união e duplicação. Inter-regional: caso de inter com r, com hífen. Conservar o primeiro elemento é essencial para decidir.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="convencao"></a>

## 4. Composto ou locução do repertório

Guarda-chuva/segunda-feira/arco-íris são hifenizados; girassol/paraquedas são aglutinados. Sala de jantar/fim de semana/cão de guarda são locuções sem hífen. Cor-de-rosa conserva a exceção, cor de vinho não recebe hífen.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-chefe"></a>

## 5. Exemplo resolvido: decisão em três passos

Em A autoaprendizagem foi retomada na segunda-feira, primeiro localize a formação auto + aprendizagem: o/a diferentes, união sem hífen. Depois reconheça segunda-feira como composto registrado com hífen. Finalmente explique por que uma condição de prefixação não decide a grafia do outro caso.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="glossario"></a>

## Vocabulário de apoio

Hífen: sinal usado na ligação escrita dos casos previstos. Prefixo: elemento que se acrescenta antes de uma base. Elemento de recomposição: elemento não autônomo, como auto/micro nos casos dados. Base: elemento ao qual se liga o primeiro. Aglutinação gráfica: união escrita sem espaço ou hífen nos casos do recorte. Tônica: sílaba com maior destaque de pronúncia. Composto: palavra formada pela combinação de elementos; os casos com hífen são dados na aula. Locução: combinação de palavras que funciona como uma expressão; seus casos também precisam ser observados.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="recuperacao"></a>

## Refazer pela condição, não pelo sinal

Identifique a formação e as letras de contato; procure a condição e a exceção pertinente. Em composto/locução, retome a forma convencional ensinada. Registre o que uma alternativa incorreta ignorou e escreva uma frase nova. Fora dos casos ensinados, consulte referência lexical autorizada; não invente uma regra universal a partir de um exemplo.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

## Recordação e recuperação

- Qual é a formação: primeiro elemento/base ou composto/locução?
- Qual condição, letra de contato ou forma convencional está presente?
- Qual exceção ou limite impede a regra universal?
