# HF-03 — Compostos e locuções: guardar formas e exceções

**Rascunho para revisão, não publicado.** Rascunho local desativado; parecer pedagógico independente concluído sem correções.

Fonte editorial: [hf-03-v1.mjs](hf-03-v1.mjs). Regenerar com `node docs/missao-bancaria/rascunhos/validate-mp01.mjs --unit=hf03 --render`.

Objetivo: Decidir o hífen pela formação, condição e exceção ensinadas, aplicando grafias em frases sem transformar o recorte em regra universal.

<a id="entrada"></a>

## 1. Nem toda combinação segue a regra de prefixos

Frase autoral: Na segunda-feira, ela deixou o guarda-chuva na sala de jantar. Segunda-feira e guarda-chuva são compostos com hífen registrados no recorte; sala de jantar é uma locução sem hífen. Procurar uma letra de contato como em auto + observação não resolve sozinho esses casos.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="compostos"></a>

## 2. Compostos registrados no recorte

Uma palavra composta combina elementos em uma unidade. Nos casos justapostos ensinados, sem palavra de ligação entre os elementos e com destaque próprio de pronúncia, usam-se formas como guarda-chuva, segunda-feira e arco-íris. São grafias convencionais registradas no Acordo. Não basta encontrar duas palavras lado a lado numa frase para criar um composto com hífen.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="aglutinados"></a>

## 3. Compostos com grafia aglutinada

Certos compostos são escritos unidos sem hífen, com perda, em certa medida, da percepção de composição: girassol e paraquedas são formas registradas. Isso não muda a grafia de guarda-chuva. Guardar uma forma lexical não autoriza decidir todos os compostos pelo mesmo padrão.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="locucoes"></a>

## 4. Locuções em geral sem hífen

Uma locução combina palavras que funcionam como expressão. No recorte, sala de jantar, fim de semana e cão de guarda são escritas com espaços e sem hífen. As palavras de ligação, como de, fazem parte das expressões. O Acordo prevê exceções consagradas; portanto, não usar a regra falsa de que toda expressão com de dispensa hífen.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="excecoes"></a>

## 5. Exceção lexical e contraste de cor

Cor-de-rosa é forma com hífen consagrada no recorte. Cor de vinho é locução sem hífen. O fato de ambas descreverem cores não torna suas grafias idênticas. Este contraste não é um método para deduzir a grafia de todas as cores ou expressões: outras formas exigem referência pertinente.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-guarda"></a>

## 6. Exemplo resolvido: um objeto

Em Ela levou o guarda-chuva, guarda-chuva é o composto registrado com hífen. Girassol é outro composto, mas sua forma convencional é aglutinada. Contar quantos elementos podem ser reconhecidos não decide sozinho a grafia de ambos.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-sala"></a>

## 7. Exemplo resolvido: lugar e expressão

Em A mesa ficou na sala de jantar, conserva-se a locução sala de jantar com espaços, sem hífen. Sala-de-jantar não é a forma do caso ensinado. A decisão retoma a locução; não aplica a regra de prefixo + h.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-cor"></a>

## 8. Exemplo resolvido: duas descrições

Em O cartão era cor-de-rosa e a capa era cor de vinho, o primeiro caso conserva a exceção hifenizada; o segundo conserva a locução sem hífen. Não se elimina ou acrescenta hífen a uma delas apenas para igualar as duas descrições.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="limites"></a>

## 9. Consulta faz parte da revisão

Não se cobram topônimos, espécies botânicas/zoológicas, todas as formas com bem/mal ou pronomes ligados a verbos. Existem outros casos com hífen. Quando a forma não foi ensinada, consulte uma entrada lexical pertinente, verificando sentido e grafia, em vez de criar uma regra pelo espaço ou pelo número de elementos.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="glossario"></a>

## Vocabulário de apoio

Hífen: sinal usado na ligação escrita dos casos previstos. Prefixo: elemento que se acrescenta antes de uma base. Elemento de recomposição: elemento não autônomo, como auto/micro nos casos dados. Base: elemento ao qual se liga o primeiro. Aglutinação gráfica: união escrita sem espaço ou hífen nos casos do recorte. Tônica: sílaba com maior destaque de pronúncia. Composto: palavra formada pela combinação de elementos; os casos com hífen são dados na aula. Locução: combinação de palavras que funciona como uma expressão; seus casos também precisam ser observados.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="recuperacao"></a>

## Refazer pela condição, não pelo sinal

Identifique a formação e as letras de contato; procure a condição e a exceção pertinente. Em composto/locução, retome a forma convencional ensinada. Registre o que uma alternativa incorreta ignorou e escreva uma frase nova. Fora dos casos ensinados, consulte referência lexical autorizada; não invente uma regra universal a partir de um exemplo.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

## Recordação e recuperação

- Qual é a formação: primeiro elemento/base ou composto/locução?
- Qual condição, letra de contato ou forma convencional está presente?
- Qual exceção ou limite impede a regra universal?

B. Guardachuva.

C. Guarda chuva.

D. Guarda-chuva.

- **C:** Substitui o hífen por espaço.
- **D:** Mantém o composto hifenizado registrado.
