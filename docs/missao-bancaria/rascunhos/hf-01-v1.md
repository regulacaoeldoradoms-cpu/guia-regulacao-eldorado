# HF-01 — Hífen: a formação vem antes das letras

**Rascunho para revisão, não publicado.** Rascunho local desativado; parecer pedagógico independente concluído sem correções.

Fonte editorial: [hf-01-v1.mjs](hf-01-v1.mjs). Regenerar com `node docs/missao-bancaria/rascunhos/validate-mp01.mjs --unit=hf01 --render`.

Objetivo: Decidir o hífen pela formação, condição e exceção ensinadas, aplicando grafias em frases sem transformar o recorte em regra universal.

<a id="entrada"></a>

## 1. Um sinal, situações diferentes

Frase autoral: A auto-observação ajuda na aprendizagem. Auto-observação tem hífen por uma condição da formação. Acento, hífen e espaço não são sinais intercambiáveis. Primeiro reconheça quais elementos estão sendo unidos; só depois examine suas letras. Não se cobra aqui toda formação de palavras.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="base"></a>

## 2. Prefixo ou elemento de recomposição e base

Um prefixo é acrescentado antes de uma base; um elemento de recomposição, como auto ou micro nos exemplos, também aparece antes de outro elemento, mas não é uma palavra autônoma nesses usos. Nesta aula chamaremos ambos de primeiro elemento, conservando essa diferença. Em auto + observação, auto expressa relação com o próprio indivíduo; observação é a base. O sinal + mostra a análise do exercício, não a grafia final.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="h"></a>

## 3. Segundo elemento com h

Nas formações deste recorte com o segundo elemento iniciado por h, usa-se hífen: super + homem → super-homem; extra + humano → extra-humano. O h da base continua escrito. Esse caso não autoriza afirmar que toda letra h em qualquer posição exige hífen.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="iguais"></a>

## 4. Mesma vogal no contato

Nos casos ensinados, se o primeiro elemento termina na mesma vogal que inicia o segundo, usa-se hífen: auto + observação → auto-observação, o/o; semi + interno → semi-interno, i/i. Compare as letras na junção, não duas vogais encontradas em qualquer lugar da palavra. Há exceções e outros prefixos, que precisam de tratamento próprio.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="co"></a>

## 5. Exceção delimitada: co com o

O prefixo co se une em geral ao segundo elemento mesmo quando este começa por o: co + obrigação → coobrigação; co + ocupante → coocupante. No caso, o contato o/o não produz hífen. Isso não apaga a regra de auto-observação, nem significa que qualquer primeiro elemento com o se comporte como co.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-auto"></a>

## 6. Exemplo resolvido: observar a si próprio

Em A auto-observação foi registrada no texto, os elementos dados são auto e observação. O primeiro termina em o e o segundo começa em o: a grafia do caso é auto-observação. Não se elimina uma das vogais nem se escreve um espaço no lugar do hífen.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-h"></a>

## 7. Exemplo resolvido: personagem fictício

Em O conto descreve um super-homem, a formação dada é super + homem. A base começa por h: conserva-se o h e usa-se hífen. O primeiro elemento terminar em r não leva aqui a duplicar h ou retirar o sinal.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-co"></a>

## 8. Exemplo resolvido: guardar a exceção

Em O texto menciona uma coobrigação, a análise é co + obrigação. O caso ensinado de co aglutina os elementos e conserva os dois o: coobrigação. Escrever co-obrigação por copiar auto-observação ignora a exceção, não aplica melhor a regra.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="limites"></a>

## 9. Uma primeira árvore de decisão

Neste recorte: identifique os elementos; veja h inicial da base ou contato de vogais iguais; confira o caso particular de co com o. Vogais diferentes e r/s serão ensinados em HF-02. Des/in com perda histórica de h e outros prefixos não são cobrados; não extrapole o exemplo super-homem para todas as formações.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="glossario"></a>

## Vocabulário de apoio

Hífen: sinal usado na ligação escrita dos casos previstos. Prefixo: elemento que se acrescenta antes de uma base. Elemento de recomposição: elemento não autônomo, como auto/micro nos casos dados. Base: elemento ao qual se liga o primeiro. Aglutinação gráfica: união escrita sem espaço ou hífen nos casos do recorte. Tônica: sílaba com maior destaque de pronúncia. Composto: palavra formada pela combinação de elementos; os casos com hífen são dados na aula. Locução: combinação de palavras que funciona como uma expressão; seus casos também precisam ser observados.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="recuperacao"></a>

## Refazer pela condição, não pelo sinal

Identifique a formação e as letras de contato; procure a condição e a exceção pertinente. Em composto/locução, retome a forma convencional ensinada. Registre o que uma alternativa incorreta ignorou e escreva uma frase nova. Fora dos casos ensinados, consulte referência lexical autorizada; não invente uma regra universal a partir de um exemplo.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

## Recordação e recuperação

- Qual é a formação: primeiro elemento/base ou composto/locução?
- Qual condição, letra de contato ou forma convencional está presente?
- Qual exceção ou limite impede a regra universal?
