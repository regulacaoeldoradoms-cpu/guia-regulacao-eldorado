# HF-02 — Vogais diferentes, r/s e o contraste com inter

**Rascunho para revisão, não publicado.** Rascunho local desativado; parecer pedagógico independente concluído sem correções.

Fonte editorial: [hf-02-v1.mjs](hf-02-v1.mjs). Regenerar com `node docs/missao-bancaria/rascunhos/validate-mp01.mjs --unit=hf02 --render`.

Objetivo: Decidir o hífen pela formação, condição e exceção ensinadas, aplicando grafias em frases sem transformar o recorte em regra universal.

<a id="entrada"></a>

## 1. O contato precisa ser identificado

Frase autoral: A autoaprendizagem organiza o estudo. Auto + aprendizagem une o com a, vogais diferentes; esse caso não usa o hífen de auto-observação. Os elementos são fornecidos nos itens, para que a decisão não dependa de adivinhar como a palavra foi formada.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="diferentes"></a>

## 2. Vogais diferentes no recorte

Nas formações ensinadas em que o primeiro elemento termina em vogal e o segundo começa por vogal diferente, unem-se sem hífen: auto + aprendizagem → autoaprendizagem; extra + escolar → extraescolar. Conservam-se as vogais; não eliminar uma letra apenas por juntar os elementos.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="rs"></a>

## 3. Primeiro elemento em vogal e base em r ou s

No caso de primeiro elemento terminado em vogal e segundo iniciado por r ou s, unem-se sem hífen e duplicam-se r/s: contra + regra → contrarregra; mini + saia → minissaia; micro + sistema → microssistema. A duplicação pertence a essa formação; não se acrescenta rr/ss a toda palavra iniciada por r/s.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="inter"></a>

## 4. Um contraste com primeiro elemento terminado em r

Com inter, hiper e super, a base iniciada por r liga-se com hífen nos casos previstos. Exemplo dado: inter + regional → inter-regional, relativo a relações entre regiões. Não usar a decisão de contra + regra aqui: contra termina em vogal; inter termina em r. O contraste é delimitado, não uma lista completa de prefixos consonantais.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-diferentes"></a>

## 5. Exemplo resolvido: autoaprendizagem

Em O material favorece a autoaprendizagem, o contato fornecido é o/a: vogais diferentes, união sem hífen e sem perda de vogal. Auto-aprendizagem transfere indevidamente a regra do contato o/o de auto-observação.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-rs"></a>

## 6. Exemplo resolvido: contrarregra

Em O contrarregra preparou o palco, a palavra designa quem ajuda a organizar os bastidores. Os elementos dados são contra + regra: termina a, começa r. Aglutina-se e duplica-se r: contrarregra. Contraregra perde a duplicação; contra-regra conserva um hífen que não cabe neste caso.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="ex-inter"></a>

## 7. Exemplo resolvido: comparação decisiva

Em O encontro inter-regional reuniu participantes, inter + regional tem r no final do primeiro elemento e r no início do segundo. Usa hífen. Em micro + sistema, o primeiro termina em o e o segundo começa em s: microssistema, sem hífen e com ss. Não decidir apenas por ver a primeira letra da base.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="limites"></a>

## 8. Não aplicar fora da formação ensinada

Nem toda palavra com rr/ss surgiu pelo processo estudado; nem todo primeiro elemento terminado em consoante segue inter/hiper/super. Outros prefixos, bem/mal, formas com pós/pré/pró e palavras estrangeiras ficam fora. Para uma formação não coberta, a consulta lexical continua apropriada.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="glossario"></a>

## Vocabulário de apoio

Hífen: sinal usado na ligação escrita dos casos previstos. Prefixo: elemento que se acrescenta antes de uma base. Elemento de recomposição: elemento não autônomo, como auto/micro nos casos dados. Base: elemento ao qual se liga o primeiro. Aglutinação gráfica: união escrita sem espaço ou hífen nos casos do recorte. Tônica: sílaba com maior destaque de pronúncia. Composto: palavra formada pela combinação de elementos; os casos com hífen são dados na aula. Locução: combinação de palavras que funciona como uma expressão; seus casos também precisam ser observados.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

<a id="recuperacao"></a>

## Refazer pela condição, não pelo sinal

Identifique a formação e as letras de contato; procure a condição e a exceção pertinente. Em composto/locução, retome a forma convencional ensinada. Registre o que uma alternativa incorreta ignorou e escreva uma frase nova. Fora dos casos ensinados, consulte referência lexical autorizada; não invente uma regra universal a partir de um exemplo.

Base conceitual: [Acordo Ortográfico — hífen no recorte introdutório](https://www.planalto.gov.br/ccivil_03/_ato2007-2010/2008/decreto/d6583.htm). Consulta: 04/10/2026.

- Qual condição, letra de contato ou forma convencional está presente?
- Qual exceção ou limite impede a regra universal?
