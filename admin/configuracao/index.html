Ordem segura de implantação

  1. Configurar AUTH_DEVELOPER_USERNAMES e AUTH_RATE_LIMIT_SECRET.
  2. Conectar Firestore, Storage e Firebase Authentication ao Worker.
  3. Publicar as regras privadas do Firebase e conferir IAM.
  4. Testar o Canal do Cidadão com as duas flags de migração ainda desligadas.
  5. Só então migrar os antigos Desenvolvedores para Coordenação.
  6. Depois de validar o envio de e-mail, iniciar a migração das contas profissionais para e-mail verificado.
Este painel não altera nenhuma configuração externa. Ele existe para confirmar o estado do ambiente sem expor segredos e evitar ativar uma migração na ordem errada.
